About the project

GeoMap is a web application that lets users create and visualize locations on an interactive map. Users can add places, which are marked with custom pins on the map. It can also store images and information about each location.

The project uses MapLibre, an open-source library for rendering interactive maps, enabling a smooth, customizable experience with no dependency on paid services.
