About the project

bgg_remote started as a real problem during my internship at Acervo Tech. The company had an integration with the BoardGameGeek (BGG) API, and at some point BGG changed its API to require authentication, breaking that integration overnight. I shipped a quick fix to get Acervo back up and running.

Once the immediate issue was solved, I looked into the existing options in the Ruby ecosystem for talking to BoardGameGeek. What I found were gems that hadn't kept up with the current API — Acervo itself had been relying on one of them before it broke. That gap is what led me to build bgg_remote: a new Ruby gem for BoardGameGeek integration.

The main goal was a simpler API, with less code and more freedom for the developer to decide how to use the returned data. It works well as a thin wrapper for BGG requests, but also ships dedicated methods for common resources, like thing, for developers who prefer a more ready-made interface. You can also skip the automatic conversion done by Crack and work directly with the raw XML returned by the API — so it's a choice between the convenience of automatic parsing or full access to the original XML, depending on what the application needs.

The gem has been published on RubyGems since, and has passed nearly 3,000 downloads. 

gem "bgg_remote", "~> 0.1.0"

You can see it in action powering Boardgame Explorer.
