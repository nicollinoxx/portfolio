About the project

This project was built in 2021 using Rails 6. It was a key step in my growth with Ruby on Rails, letting me dig deeper into the language and the framework. The application is a tweet scheduling system, where the user can schedule messages to be sent directly to Twitter. For example, if a tweet is scheduled for a 2-hour interval, it is sent automatically as soon as that time elapses.

For more details about the project, check out the post Tweets Agendados (in Portuguese).
