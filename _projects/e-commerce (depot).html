About the project

Depot is a storefront application built as part of a Rails learning tutorial. It was developed to explore and implement core e-commerce features, such as product management, a shopping cart, and order processing. The source code is available in the Learning-storage repository on my GitHub profile.
For more details about the project, check out the post E-commerce "Depot" (in Portuguese).
